# Aprender a programar con AI — Curso Ian

Curso personalizado para Ian (16 años, ex-alumno de Federico en Algorítmica) para aprender a programar usando Claude Code.

**Profesor humano**: Federico Peña (mentor + coach)
**Tutor AI**: Claude (sesiones día a día, instrucciones en `CLAUDE.md`)
**Estudiante**: Ian
**Inicio**: mayo 2026
**Duración**: 8 sesiones de 90 min, 2-3 sesiones/semana, ~3-4 semanas total

## Cómo está organizado este repo

```
ian-aprende-claude/
├── CLAUDE.md           ← instrucciones para tu tutor AI (Claude lo lee solito)
├── README.md           ← este archivo
├── sesiones/           ← el plan de cada sesión
│   ├── sesion-1.md
│   ├── sesion-2.md
│   └── ... hasta sesion-8.md
├── bitacora/           ← lo que aprendiste cada sesión (lo escribes tú)
│   └── sesion-N.md     ← se crean conforme las completas
└── proyectos/          ← el código de tu proyecto (lo creas tú con Claude)
```

## Las 8 sesiones

1. **Hola Claude** — instalar Claude Code, primer "hola mundo"
2. **Tu propio repo en el mundo** — GitHub, git, markdown
3. **Tu primer proyecto real** — elegir scope, definir alcance
4. **Cuando Claude se equivoca** — debugging, verificar, leer errores
5. **Hacer que la cosa hable con el mundo** — APIs, datos, autenticación básica
6. **Deploy** — publicar tu proyecto en internet
7. **Enseñarle a Claude tu contexto** — CLAUDE.md, skills, memoria
8. **Capstone** — demo final + presentación

## Reglas del curso

1. **Una pregunta a la vez.** No le pidas a Claude 5 cosas juntas.
2. **Lee los errores ANTES de pedir ayuda.** En español, no en inglés.
3. **Si copias código sin entender, paras.** Mejor pregúntale a Claude que te lo explique.
4. **Cada sesión termina con bitácora.** Tres frases en `bitacora/sesion-N.md`:
   - Qué aprendí hoy
   - Qué me costó
   - Qué quiero hacer la próxima
5. **Si te frustras, eso es parte del aprendizaje.** No es señal de que no puedas.
6. **Si Claude te dice algo raro, verifícalo.** Las AIs alucinan a veces.

## El gran objetivo

Al final del curso vas a tener:
- Un proyecto tuyo funcionando en internet, con URL pública
- Un repo de GitHub que puedes compartir
- La habilidad de construir cosas con software y AI
- La identidad de "alguien que construye"

No es un curso para "aprender a programar". Es para activarte como creador.
