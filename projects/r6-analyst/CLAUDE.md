# CLAUDE.md — R6 Analyst

## What this project does
Analyzes given info about an opponent in Rainbow 6 Siege, stores it, and finds patterns to predict their behavior.

## Tech stack
- Python (backend logic)
- Flask (web server)
- JSON (data storage)
- HTML/CSS/JavaScript (frontend)
- Gunicorn (production server on Render)

## How to talk to me
Casual and direct. Hacker energy when things are going well, normal English when explaining something important or when I'm stuck. Don't over-explain. One thing at a time.

## Decisions already made
- Web app (not terminal-only)
- No voice features in v1
- No map overlay UI in v1
- Data stored in a local JSON file
- Deployed on Render at https://ian-learns-claude.onrender.com
