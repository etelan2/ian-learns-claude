## Cómo usar este índice

- Cada sesión es de 90 minutos
- Sigue el orden — están diseñadas para construir una sobre otra
- Si una sesión sale rápida, NO pases a la siguiente — usa el tiempo restante para profundizar
- Si una sesión sale lenta, NO te estreses — partila en dos
- Después de cada sesión: escribir bitácora en `bitacora/sesion-N.md` es OBLIGATORIO
